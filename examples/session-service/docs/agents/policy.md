# Example project policy

The planner assigns and owns the frontier. An executor edits the assigned document, returns a PR
and evidence, and never self-merges. A separate reviewer evaluates wording and actual whitespace
checks on the submitted head. An operator performs the authorized merge. Target changes are reserved.
Only an offline lane exists; there is no service access. Runtime behavior remains unverified.
After merge, run the docs gate on final main and record the outcome before closing the round.
All identities and claimed outcomes in this teaching fixture are fictional; do not publish them.
